# Indicadores económicos de Chile (React + Vite + Tailwind)

Visualiza los indicadores de hoy, busca un valor por fecha o rango, grafica un año, revisa los últimos 30 días y compara dos indicadores. Datos: [mindicador.cl](https://mindicador.cl).

Migración del proyecto Angular original. Lee **GUIA.md** para la explicación y los ejercicios.

```bash
npm install
npm run dev
```
